PRODUCT PREVIEW

01 / CAPABILITIES

能替你做的事

六件，今天就能用。

  • 01

    多模型切换

    模型在设置里换，每个还剩多少额度也在那儿看。默认用哪个，由管理员配好。

    快速深度视觉
  • 02

    会算数

    复杂算式交给计算器算，不让模型心算。

  • 03

    读文件

    PDF、Word、纯文本、代码文件都能读。图片要看当前模型有没有视觉能力，没有的话它会直接说读不了。

  • 04

    长期记忆

    你说过的偏好会存下来，下次聊到相关的事自动带上。存了哪些，在设置里能看也能删。

  • 05

    能查实时信息

    需要新信息时先搜网页再回答，答案后面附来源。查不到就说查不到。

  • 06

    多人各用各的

    每个人的会话、文件和记忆各自独立，互相看不见。

02 / WHAT'S DIFFERENT

不一样的地方

三件，用久了才看得出来。

  • 01

    记得住，也攒得下

    偏好、习惯、正在跟进的事，说过一次就留下。日程和对话用的是同一份记忆，不用在两个 App 之间搬运。

    别处也有记忆，但换一个工具，就得从零再交代一遍。
  • 02

    办到一半会回来问

    要分几步的事交给它，它自己往下走；走到需要你拍板的地方停下来问，你回一句它接着跑。

    多数助手只有一问一答：答完就结束，剩下的还是你自己办。
  • 03

    换模型不换脑子

    今天用这家，明天换那家，记忆、会话、日程都留在原地。

    客户端换模型等于重新养一遍，云端产品根本不让你换。

03 / ON ANDROID

安卓版

安卓版比网页多三样：到点提醒、系统分享、桌面小组件。装的时候会问要不要给「精准闹钟」权限，不给也能用，只是提醒可能晚几分钟。

下载安卓版 ↓
  • 01

    到点提醒

    在设置里定个时间，到点手机弹通知。提醒只存在手机里，不传到服务器。

  • 02

    直接分享

    在相册或文件里点分享，选 Fenver，文件就作为附件发过去。看不看得懂内容，取决于当前模型有没有视觉能力。

  • 03

    桌面小组件

    放桌面上看今天的提醒，点一下就能新建对话，或者发张图问它。识图要模型支持视觉。

05 / GET STARTED

怎么开始

打开网页，注册一个账号，就能用。

  1. 01打开 Fenver

    访问 ai.fenever.xyz/app/，安卓版可直接跳转。

  2. 02注册账号

    起个用户名，设个密码，再填几个只有你知道答案的问题——忘了密码靠它找回。

  3. 03开始用

    换台设备登同一个账号，聊天记录和记忆都还在。

要是提示没有可用模型，那是管理员还没配，跟你账号没关系。

08 / FAQ

常见问题

常被问到的六个问题。

01要自己配 API 密钥吗？

不用。模型由管理员配好，你什么都不用填。

02换手机 / 重装 App，记录会丢吗？

不会。聊天记录、附件、记忆都挂在你这个账号下，换台设备用同一个用户名登录就都在。提醒存在旧手机本地，不跟账号走。

03谁能看到我的数据？

只有你。会话、附件、记忆都按账号分开存，别的注册用户碰不到你的。

04怎么删干净？

会话和记忆条目在设置里逐条删。要连账号一起注销，得找管理员；记忆库里哪些会跟着删，删之前先问清楚。

05有 iOS 吗？

没做。Safari 打开 ai.fenever.xyz/app/ 一样能用，加到主屏幕后基本满屏，只是没有提醒、分享入口和桌面组件。

06打不开怎么办？

这台助手跑在我的一台电脑上。关机、断网，或者重启后没人登录，它就连不上。不是你的账号出了问题，过一会儿再试。
