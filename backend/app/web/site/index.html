01 / CAPABILITIES

它能做什么

六项都在线上跑着，注册完就能用。

  • 01

    多模型切换

    在设置里换模型，每个模型的额度也在这里看。默认用哪个由管理员配好。

    快速深度视觉
  • 02

    会算数

    复杂算式交给计算器算，不让模型心算。

  • 03

    读文件

    PDF、Word、纯文本、代码文件都能读。图片要看当前模型有没有视觉能力，没有的话它会直接说读不了。

  • 04

    长期记忆

    你说过的偏好会存下来，下次聊到相关的事自动带上。存了什么在设置里能看能删。

  • 05

    能查实时信息

    需要新信息时先搜网页再回答，答案后面附来源。查不到就说查不到。

  • 06

    多人各用各的

    每个人的会话、文件和记忆各自独立，互相看不见。

安卓版

除了网页能做的，安卓版还加了提醒、系统分享和桌面小组件。它会申请「精准闹钟」权限；不给也能用，只是提醒时间可能差几分钟。

下载安卓版 ↓
  • 01

    到点提醒

    在设置页创建提醒，到时推送系统通知；提醒本地存储，不上传云端。

  • 02

    直接分享

    相册、PDF 直接点分享发送至助手，文件自动作为附件；能否识别内容取决于当前模型的视觉能力。

  • 03

    桌面小组件

    展示当日提醒，可一键发起识图提问、新建对话；需要视觉模型支持。

07 / FAQ

常见问题

下面六个是问得最多的。

01要自己配 API 密钥吗？

不用。模型由这台助手的管理员配，普通人什么都不用填。

02换手机 / 重装 App，记录会丢吗？

不会丢。聊天记录、附件、长期记忆都在服务器上你这个账号里，用同一个用户名再登录一次就回来。提醒存在旧手机本机，不跟着账号走。

03谁能看到我的数据？

只有你。会话、附件、记忆按账号隔离，别的注册用户看不到你的。

04怎么删干净？

设置里删会话与记忆条目。要注销整个账号，联系这台助手的管理员做删除；记忆库里哪些会一起被抹掉，删之前当面问清。

05有 iOS 吗？

没有壳，但 Safari 打开 ai.fenever.xyz/app/ 一样能用，加到主屏幕后接近全屏体验，只是没有提醒、分享入口和桌面组件。

06打不开怎么办？

这台助手跑在一台个人电脑上。机器关机、断网，或者重启后没人登录，它就会暂时够不着。那不是你的账号出了问题，等一会儿再试。
