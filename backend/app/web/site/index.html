01

能做什么

六件已经能用的事。没有“即将上线”的占位，也没有把模型能力说成产品开关。

  • 01

    多模型切换

    在可用模型间快速切换。模型列表、额度在设置页查看，默认模型由服务端配置，无需手动设置。

  • 02

    会算数

    复杂运算调用计算器工具，本机安全解析算式，避免模型心算出错。

  • 03

    读你发过去的文件

    支持 PDF、docx、txt、代码文件提取文本；视觉模型可识图，无视觉能力的模型会拒绝。

  • 04

    长期记忆

    自动保存你的偏好，相关对话可自动唤起记忆；记忆内容可在设置页查看、删除。

  • 05

    能查实时信息

    模型可以先联网搜索再回答，结果取自公开网页搜索并附来源链接。查不到时会说查不到，不会替你编一个。

  • 06

    多人各用各的

    会话、文件、记忆独立绑定账号，用户数据互相隔离、不可见。

02

移动端
多做一点

可解锁系统通知、分享入口、桌面小组件。应用会申请「精准闹钟」权限，未授予时改用更省电的排期方式，时间可能略有延迟。

  • 01

    提醒

    在设置页创建提醒，到时推送系统通知；提醒本地存储，不上传云端。

  • 02

    分享

    相册、PDF 直接点分享发送至助手，文件自动作为附件；能否识别内容取决于当前模型的视觉能力。

  • 03

    桌面组件

    展示当日提醒，可一键发起识图提问、新建对话；需要视觉模型支持。

04

三步上手

没有安装向导，没有密钥配置。打开网页就能开始。

  1. 01 访问 ai.fenever.xyz/app/

    安装壳包可直接跳转。

  2. 02 注册账号

    填写用户名、密码，设置密保问题用于找回密码。

  3. 03 开始对话

    更换设备登录同一账号，聊天记录与记忆可同步。

提示：若提示无可用模型，是管理员尚未配置模型，与你的账号无关。

07

常见问题

先回答最容易被问到的六件事。

01要自己配 API 密钥吗？

不用。模型由这台助手的管理员配，普通人什么都不用填。

02换手机 / 重装 App，记录会丢吗？

不会丢。聊天记录、附件、长期记忆都在服务器上你这个账号里，用同一个用户名再登录一次就回来。提醒存在旧手机本机，不跟着账号走。

03谁能看到我的数据？

只有你。会话、附件、记忆按账号隔离，别的注册用户看不到你的。

04怎么删干净？

设置里删会话与记忆条目。要注销整个账号，联系这台助手的管理员做删除；记忆库里哪些会一起被抹掉，删之前当面问清。

05有 iOS 吗？

没有壳，但 Safari 打开 ai.fenever.xyz/app/ 一样能用，加到主屏幕后接近全屏体验，只是没有提醒、分享入口和桌面组件。

06打不开怎么办？

这台助手跑在一台个人电脑上。机器关机、断网，或者重启后没人登录，它就会暂时够不着。那不是你的账号出了问题，等一会儿再试。
