token 数一律取上游回传的 usage，服务端不估算。上游没回数字的那几次各项记 0，并在「账全不全」里点出来：那种行的 token 是个下限，不是准确数。

这是另一本账（/v1/admin/search-usage）：按「这一天 · 这一个源」记 web_search 真跑了多少次、每个源成功率。它没有「谁」这一栏——搜索工具只收 query，拿不到调用者身份。账本里没有查询原文，也没有哈希。
