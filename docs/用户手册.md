# AI智能助手 - 用户手册

## 📦 怎么开始用

**没有安装包，也没有要装的客户端。** 这台助手跑在一台机器上，您用到的一切都由服务端
下发，所以以后改版您什么都不用做——打开就是当前那一版。

### 系统要求

手机或电脑上有个现代浏览器就行。**不需要 Windows，不需要装 Python。**

### 两种用法，选一种

#### 用法一：浏览器直接开（最省事，推荐先这样试）

打开这个地址：

```
https://ai.fenever.xyz/app/
```

它会当场弹出登录/注册界面。第一次用点「注册」，自己起一个用户名、设一个密码就能开始
（不需要找任何人要码）。想以后一直能开，把它"添加到主屏幕"即可。

#### 用法二：装一个约 100 KB 的壳（只有三项功能需要它）

从发布页下载 `ai-assistant-<版本号>.apk`（例如 `ai-assistant-0.13.apk`），传到手机点开安装。

- 它会提示"禁止安装未知来源应用"——去 **设置 → 应用 → 允许来自此来源的安装**，勾选一次
  即可。
- 装完之后它**仍然**打开上面那个地址。壳里只有一个钉死的网址，**不含任何口令或密钥**，
  所以它小到可以直接当文件传给您。
- 但有三件事**只在装了本包的手机上有**（浏览器拿不到系统通知、分享入口和桌面组件）：
  - **提醒**：设置 → 设备 → 提醒。到点弹系统通知，手机重启后依然生效。提醒存在这台手机上，
    不上传服务器。v0.18 起会申请「精准闹钟」权限（Android 12+ 要在系统设置里给）；
    不给也能用，只是改用更省电的排期，**可能晚几分钟到**。同一页顶部现在常驻一行，
    写着通知授权、闹钟档位各是什么状态，每条提醒还带着"上次什么时候真发出去了、几次到点没发出去"。
  - **分享进助手**：在相册或 PDF 上点「分享」→ 选「AI 助手」，文件会挂到助手的附件栏里，
    不用先存再传。
  - **桌面组件**：主屏放一个小组件，显示今天的提醒，两个按钮直达拍照提问与新对话。

⚠️ 由此得到一条界分：**改界面不用重装，改壳的这三项功能要重装。**

### 关于"更新到新版本"

- 界面、模型、聊天记录这些：**没有更新这个动作**。服务端换了一版，您下次打开就是那一版。
- 只有装了用法二那个壳、而且**壳本身**的功能升级了，才需要去发布页下载新的 apk 装上。

## 🔧 密钥与模型：这一节您可能整节能跳过

**普通人不需要配任何东西。** 如果打开后提示「当前没有可用模型，请联系管理员配置模型服务」，
那不是您的问题，是这台助手的主人还没接上模型——找他。

只有**管理员**才需要往下读：

- 模型密钥有两个地方可配，任选其一：
  - **界面里**：登录管理员账号 → 设置 → **模型服务**（这一面对普通用户全是 403，入口
    平时也不会显示给您）。
  - **服务器本机**：那台机器的项目根 `.env`（不是"安装目录下的 `run_backend\.env`"——
    那个目录每次重建都会被整体删掉，写在那里的密钥会跟着消失）。
- 管理员自己的入口是 `https://ai.fenever.xyz/admin/`，口令框里填的是那把 bootstrap
  管理员口令（`ACCESS_TOKEN`）。**这把口令不会发给任何用户**，用户拿到的是自己注册换出来
  的个人令牌。完整规则见 `docs/安装部署指南.md` 的「🔐 多用户部署」一节。
- **搜索源的服务端密钥**（v0.32 起可选）也在管理员的界面里配：设置 → 搜索源 →
  「服务端密钥」，不配也完全能用——系统自动落到兜底搜索源，用户侧无感。配法、没配时
  的表现与验证路径都写在 `docs/安装部署指南.md` 的「搜索源：配置与 key 管理」一节，
  本手册不重述第二套口径。

> **本手册此前这十几行教的是另一条路**：下载 `AI智能助手_Setup.exe`、按向导装进
> `C:\Program Files\AI_Assistant`、双击桌面图标、打开安装目录去改 `run_backend\.env`。
> 那条桌面客户端路线已经否决并且整体删除了：仓库里现在既没有 `installer.nsi`（那个
> `.exe` 唯一的来源），也没有任何一条 CI 会产出它——照着做的人会在第一步就找不到文件，
> 然后以为服务坏了。留着比不写更糟。

## 🔑 注册与登录（多用户）

从这一版起，**每个人用自己的身份**访问同一个助手：会话、附件、长期记忆都挂在身份上，
别人看不到您的，您也看不到别人的。

### 1. 打开就能注册（分两步）
这台设备从来没登录过时，弹层**直接开在注册那一屏的第一步**（已存过令牌则开在登录）。
注册是**两步**：

**第一步**（自己填两项，外加一次确认）：

- **用户名**：自己起，被占用会当场在那一格下面提示，换一个即可
- **密码**：至少 8 位，自己记好——服务端只存它的 bcrypt 摘要，没有人能替您找回
- **确认密码**：再敲一遍。两次不一样时界面**当场就拦下来**，不会白跑一趟服务器

**第二步**（三道题的答案）：题面是**全站固定**的那三道，人人同一份：

1. 你的手机号后四位是什么？
2. 你小学在哪上？
3. 你父母姓氏的拼音首字母各一个是什么？

三道**都要填**，答案是**只有您自己知道**的那三句话——不是题目本身。它们和密码一样
只存这台机器上的 bcrypt 摘要，管理员也看不到原话。别敷衍：题目公开，所以整套找回路的
强度就是这三句话的强度。三格各自要注意的事：

- **手机号后四位**：换号之前先改答案，否则那道门跟着号码一起没了（改答案目前没有界面入口，
  见下面「答案也忘了」那节；换号前找管理员最稳妥）。带 0 的照原样填，例如 `0042` 就填 `0042`。
- **小学**：填您自己叫它的那个名字，别填教育局文件上的全称——全称是亲戚都查得到的东西。
- **父母姓氏首字母**：两个字母，按"父、母"的顺序。别顺手写成拼音全拼，也别用对方公开
  场合里出现过的组合（家长群、请柬上都能读到姓）。

成功后服务端发回**一枚个人令牌**，它只在这一屏出现一次，之后只存在您这台设备的
浏览器里（localStorage），关掉页面也还在。**密码不会被拿去当请求凭据**：它只用来
换令牌，换完就从输入框里清掉。

### 2. 换手机 / 重装 / 多台设备一起用
现在**不需要找管理员**：在新设备上用同一个用户名 + 密码登录即可，它会再发一枚令牌，
而旧设备那枚**继续有效**（手机、桌面、浏览器各算一台，最多同时留 8 枚，超了丢最老的）。

只有这一种情况才需要管理员动手：

- **怀疑密码泄露**——让他执行轮换，它会一次作废您**全部**设备的令牌：
  `POST /v1/admin/users/<您的 user_id>/rotate-token`

**忘了密码**不用找任何人：登录页点「忘记密码」，界面上只有**两个输入屏幕**，加上提交后
自动回登录那一下——

1. 输入您的**用户名**（这一步不问服务器任何东西）；
2. 一次交出**三道固定题的答案 + 新密码 + 确认新密码**（同一屏填完），
   点「改密码并去登录」；
3. 提交成功后界面自动回到**登录**那一屏——第三个"步"就是这一下。

三点要知道：

- 答案与新密码是**一次提交**的。中途不会告诉您"这一题对不对"：那等于给外人留一台
  能回答"这一句猜对了吗"的机器，三题就变成三次小猜。所以**三道必须全对**，
  错任意一道只得到同一句「答案不正确」，填错了要整段重来；
- 改密成功之后，您**所有设备上的登录都会掉线**，用新密码重新登录即可——这正是它的目的
  （会去点"忘记密码"的人，多半正怀疑账号被别人用着）；
- 同一个网络出口 24 小时内最多**三次**成功改密。这一条是为了让"慢慢试到成功为止"划不来，
  代价是同宿舍/同公司出口的人共享这三格。

**答案也忘了**就真没有路了：系统里没有邮件或短信通道，也没有任何人能替您改密码
（管理员手里只有停用、轮换令牌、删号三件事，**没有"代客改密"这个接口**）。
那个账号的历史会话与记忆不会跟到新账号，所以那三句答案请填您**多年后还记得**的东西。

### 3. 被停用了怎么办
管理员停用某个用户后，他的令牌**当场失效**，而且**停用的账号连密码正确也登不进去**。
这个操作是**可逆的**：

```
POST /v1/admin/users/<user_id>/disable   # 停用
POST /v1/admin/users/<user_id>/enable    # 恢复，令牌无需重新发放
```

所以被停用又恢复之后，您**原来那枚令牌继续能用**，不必重新注册。

### 4. 界面上那几句提示分别是什么意思
| 您看到的 | 实情 | 该怎么办 |
| --- | --- | --- |
| 「还没有登录：用用户名和密码登录，或注册一个」 | 这台设备还没存过令牌 | 注册或登录一次 |
| 「登录已失效：本机令牌已被服务端拒绝（管理员撤销或轮换过），重新登录即可」 | 令牌存过、但已作废 | 重新登录；**不是您输错了口令** |
| 「登录失败：用户名或密码不正确」 | 用户名不存在、密码错、或账号被停用——服务端**刻意不分**这三种 | 核对用户名与密码；确定没输错就找管理员 |
| 「该用户名已存在」（红字在用户名那一格下面，焦点也跳回那一格） | 名字撞了 | 换个用户名再点一次；这一格会计进该来源的失败预算 |
| 「注册失败：密码至少 8 位」 | 密码太短 | 加长一点（这种手滑**不**记账） |
| 「注册失败：答案至少 2 个字符」 | 某一道题的答案只写了一个字 | 写长一点（这种手滑**不**记账） |
| 「注册失败：找回的 3 题答案都要填，且每题至少 2 个字符」 | 只交了两道（或四道）答案。界面本来就不许空着提交，所以您基本碰不到这句——它主要是给不走浏览器的调用方准备的 | 三道都填上（同样不记账） |
| 「答案不正确」 | 三道题没全对、这个用户名没注册、这个人当年没留答案、或账号被停用——服务端**把这四种说成同一句话**，不告诉您是哪一种 | 核对用户名与三道答案；确定没错就是那个账号没留下找回凭据，找管理员（这一格**要**记账，见下一行） |
| 「尝试次数过多，请稍后再试」(429) | 同一个网络出口把某一格预算用完了：十分钟内错 10 次口令/撞名、十分钟内猜错 10 次找回答案、或今天已经成功注册/成功改密各满 3 次 | 等提示的 `Retry-After`（10 分钟那两本、24 小时那两本各算各的）。**这四本账只进不出**：中间登录成功、注册成功都不会让等待提前结束——真人十分钟内连错十次就是要等这一轮窗口过去（2026-09-18 终审 F3 有意选的取舍，理由与代价见部署指南"真实访客 IP 限流"一节） |

## 💡 使用技巧

### 聊天功能
- 在输入框中输入问题，按回车或点击发送
- 支持多轮对话，上下文会自动保留
- 可以切换不同的AI模型

### 回答任务（「需要你输入」）

有些事助手一次问不全，例如让它「记一条周末的日程」却听不出具体是哪天。这时任务会停在
「需要你输入」等您补一句话：

- 网页端与安卓端的任务面都会显示问题原文和「需要你输入」卡片；填进去提交后，助手从
  断点接着跑，已经做过的步骤不会重来，也不会把那部分钱再花一次。
- 停着不回答**不算失败**：刷新页面或服务重启后它仍在。默认配置下没有回答时限；只有
  运维显式开了作废窗口，等太久才会变成「已停止」（不是「没办成」）。
- **只有任务发起人本人能回答**：换一个账号（包括管理员）看不到回答入口，服务端也只认
  任务属主。管理员在 `/admin` 的任务表里能看见问题原文，但那是只读的。
- 答「随便」「不知道」也不会被反复追问：助手会按默认（通常是今天）先记下并说明。

### 会话管理
- 左侧列表显示所有历史会话
- 点击会话可切换到该对话
- 可以删除不需要的会话

### 搜索与来源引用（v0.32）

问它需要实时信息的事（当天的新闻、今年的简章、刚改的价格），助手会自己去搜网页。
回答正文上方会出现一条可折叠的横条：「**查看 N 个步骤 · M 个网页**」（例如"查看 2 个
步骤 · 3 个网页"），点开能核对它到底搜了什么、搜到的话有没有根据。展开后是这样：

- 每一回搜索占一行：「**搜索：关键词 · 来自 博查**」（也可能是 Tavily 或 必应）。
  「来自」说的是这一发**真正给出结果的搜索源**——排在前面的源暂时不好用时它自动换下一个，
  这一切发生在服务器那头，您不用配置任何东西。
- 搜索行下面逐条列出命中的网页：**标题就是链接，点一下直接在新页面打开原站**；
  标题旁边写着域名，通常还有一行源站带回的摘要。想核实"这句话凭什么"，展开这条
  横条、点链接到原站看，不必只听助手说。
- 搜不到东西时它会如实说查不到（也可能换个关键词再试一次）——它不会把"没搜到"
  说成"不存在"，您也不必替它猜。
- 摘要不够用时，助手可以**打开其中一条结果的正文**再回答：一次只读一页，每页最多约
  3000 字，而且只能读你自己最近 10 分钟搜索结果里拿到句柄的那几条网页。读不到时它会
  直说这一页读不了（比如是 PDF、图片，或页面要靠脚本才能显示），您可以让它换一条或
  不读——**您不需要做任何配置**。同一个账号 10 分钟内最多读 4 页。

两个补充：

- **自己有博查 / Tavily 的 API key** 的话，设置 → 搜索源 里有一格「本机直连」：
  key 只存在您这台设备上，在那一页发起的搜索由页面直接问源站、不经本站服务器。
  注意**聊天里助手触发的搜索不走您这一把 key**，仍走服务器上的搜索源——那一格是
  独立的直连入口，不是给聊天"提速"的开关。
- 管理员看到的「搜索用量」账本只有次数和成功率，**没有任何查询原文**；您在对话里
  看到的"搜了哪个词、搜到哪些网页"属于您自己的会话记录，和聊天记录存在一起。

### 记忆功能
- AI 会记住这四类话：您明确交代的（"记住…""以后都…"）、对它的纠正、您自述的身份与
  长期偏好、您报的学习进度。普通的一次性提问不进长期记忆——那样库里全是"帮我改一下
  这句话"，真正该想起来的反而被挤掉
- 可以在设置中查看和管理记忆
- 支持手动添加和删除记忆

### 管理员接入的本机工具（v0.37.5）
**默认关闭，普通用户不需要配置任何东西。** 管理员可以把本机的 MCP stdio 工具接入助手；
这些工具**只允许管理员执行**，而且每次执行都要在确认卡片上点一次允许。普通用户即使
在自己的工具清单里看到 `mcp_...` 这样的名字，也执行不了——服务端会直接拒绝，不会启动
任何本机进程。本版**没有新的用户配置项**；有没有可用的外部工具、开关开没开，都以
管理员的服务端配置为准。

## ❓ 常见问题

### Q: 打开网址什么也没有 / 浏览器显示 5xx？
A: 分两种，看提示就知道是哪一种：
- **界面上写"服务端还没有可用的模型，请联系管理员配置模型服务"** → 服务活着，但那台机器
  还没配好可用的模型（配了但没填密钥也算）。找管理员。
  注意**没有"按人授权模型"这回事**：模型是全局的，管理员配好之后所有人同时能用，
  没配则所有人同时不能用——不用去要一个谁也给不出的授权。
- **502 / "无法连接"** → 服务本身当时不在线。这不是您手机的问题，重试也没用；如果您装了
  壳，它同样打不开。

### Q: 聊天没有响应？
A:
1. 看上面那一格——先确认服务在线；
2. 检查手机网络（`https://ai.fenever.xyz` 要能通到公网）；
3. 界面上那句话**开头是不是「模型调用失败：」**。是 → 服务是活的，是它背后接的那个模型
   当时不可用，冒号后面跟着的就是原因；换一个新对话再试一次，反复如此就把那句原话发给
   管理员。不是这个开头 → 回到第 1 条。

### Q: 我换了手机 / 重装了 App，记录会丢吗？
A: **不会**。会话、附件、长期记忆都挂在您的**账号**上，不在手机里。新设备上用同一个
用户名 + 密码登录即可。只有两样是**按设备**留的：这台设备上存的那些个人令牌，和壳自己
的东西（提醒、待上传的分享件）——它们**按账号隔离**，换账号后看不见上一个人的。

### Q: 我不想用了，怎么删干净？
A: 分两层，别混：
- **这台手机上**：设置 → 账户 → 在**别的**身份那一行点「删除账号」。当前正在用的这一行
  两颗按钮都没有（换人不需要按钮，而"删除"落在自己身上只会把正在用的会话打断），
  所以要先切走或登出才点得到。这只清**本设备**存的那个身份，服务器上那份记录还在。
  装了壳的话，把壳当普通应用卸载即可。
- **服务器上**：目前没有"本人自助删号"这个按钮，得请管理员在 `/admin` 页执行删除
  （`DELETE /v1/admin/users/<user_id>`）。**并且要说清这条接口的边界**：它只把您从身份
  表里划掉，**不会**顺带删除您名下的会话、附件与长期记忆条目——那些会以"查无此人"的
  形式留在服务器上。所以真要把数据清干净，找管理员时请明说"连会话和记忆一起清"，
  那需要他手工再处理一遍。

### Q: 如何更新到新版本？
A: 见上面「关于"更新到新版本"」那一节——**界面不用更新**。只有壳的三项功能（提醒 /
分享进助手 / 桌面组件）升级了才重装 apk。
