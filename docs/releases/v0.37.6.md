# v0.37.6 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：安卓 `versionName` 保持 `0.36.4`，官网与 App 的检查更新仍按现有清单报最新可安装版本（以 `data/version.json` 与 `/site/version.json` 为准，本说明不写死）。这一版给管理台补上第六个分区 **MCP 外部工具**的可视化管理，并修掉管理台桌面端多渲染一份手机专属卡片的回归。

## 新增了什么

- **管理台 MCP 分区**：`/admin/` 新增第 6 个 tab，把 v0.37.5 已有的 MCP stdio 管理端点接成页面。分区里能看到全局开关和每条 server 的状态：`id`、`state`、`pid`、`tools_total`、`tools_exposed`、`restarts`、`last_error`、`env_names`、`command_basename`；支持新增条目、整条替换已有条目与删除条目。
- **写操作走管理台既有鉴权**：页面只用管理员 Cookie 加 `X-CSRF` 发请求，全部落在既有 4 个 `RequireAdmin` 端点上，不新增后端接口。
- **状态不显示参数值**：状态区只渲染服务端投影里的字段，不显示 `args` 或 env 的值；编辑已有条目时 **args 需要重新填写**——保存是整条替换，不重新填就等于清空原参数，表单旁与二次确认里都写明了这一点。
- **仍是默认关闭、仅管理员、逐次审批**：MCP 全局开关默认 `false`，条目默认空表；每次工具调用仍需单独审批。这一版只是给既有端点和开关做可视化，**不改变后端安全边界**；管理台把话说清楚：这**不是沙箱**。
- **手机端导航与渲染**：手机底部导航从 5 列改成 6 列，第六个分区点得到；页面状态文本用 `textContent` 建树，不拼 HTML 字符串。

## 修复了什么

- **#181 管理台桌面端 mobile-only 卡片泄漏**：账号卡、安全事件卡与这次新增的 MCP 卡都带手机专属样式，桌面端只显示表格与桌面内容，这些卡片只在手机媒体查询里放出来。补了成对回归锁：同一条判据同时钉住「桌面隐藏」与「手机显示」，并钉住手机断点那条规则排在桌面隐藏之后、底部导航确为 6 列。

## 边界

- **没有新 APK**，本版不涉及安卓包；真实手机上的视觉复测仍需用户在自己的设备上确认，代码锁只能证明样式表没写反。
- MCP 子进程仍拥有服务账号权限，Windows Job 分配与 `CreateProcess` 之间存在毫秒级竞态，`args` 里的值在 `data/config.json` 中仍是明文，第三方工具输出仍可能包含 prompt injection——这些既有残余本版**不变**，审批与「仅管理员」仍是主防线。
- 本版**不新增配置键**，也不改更新通道；MCP 的两个键与四个端点仍以 v0.37.5 的说明为准。
