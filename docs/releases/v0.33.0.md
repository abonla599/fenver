# v0.33.0 更新说明

## 修复了什么

- 登录状态不再永久有效：新签发的会话令牌 30 天到期，改密码或退出登录后手上的令牌立刻作废；升级前就已登录的账号另有一次 30 天宽限，宽限从升级后第一次写盘那刻起算、不会因为你一直在用而往后挪，宽限期内在用设备不会被要求重新登录
- 同一份数据目录不再允许两个服务进程同时写：第二个进程启动时直接被拒绝并告知是谁占着这份数据，不会再出现两边各存一份、互相整体覆盖且都以为自己写成功的情况
- 需要批准的高危工具动作现在真正在闸门后面执行：没批准就在执行那一步被拦下，批准后才落地
- 管理员把模型服务地址填成内网、本机或云厂商元数据地址会被拒绝并给出可读原因，服务端不再替这些地址出网；确实把模型自建在本机的部署，需要显式打开开关才能保存
- 更新仓库地址不再允许拼出 GitHub 之外的取值
- 对外的 `/health` 探针不再回显模型服务的名称与型号，也不再回显服务端目录路径；具体是哪条模型配置坏了，只看服务端日志

## 优化了什么

- 上传的图片改成真实解码校验：只把开头几个字节伪装成图片、正文是别的内容的文件会被拒收
- 对外的健康与自检信息只留状态、一句原因和几个数字，身份类信息一律不出公网
- Docker 镜像不再把本地构建产物、源码副本、可执行文件与日志打进包体，镜像体积相应下降
