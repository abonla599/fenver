# v0.35.0 更新说明

<!-- scope: installer -->

本版有安卓包（0.35.0），服务端与网页端同版更新。装上之后，聊天里的任务停在需要你补一个答案的地方时，会直接出现「需要你输入」卡片；回答后从断点继续，已经跑过的步骤不重跑。

## 新增了什么

- **「需要你输入」卡片**：任务或工具停在需要你补一个答案的地方（例如“周末买菜”这种没有具体日期的说法），网页端和安卓端都会把问题原文显示出来，填写后从断点继续。
- **任务状态以读接口为准**：刷新页面或服务重启后，卡片和问题仍在；不会因为进程重启就丢掉还能继续的断点。
- **取消更诚实**：答案正在被处理时点取消，会明确告诉你“这次取消未被接受”，不会把刚递进去的答案悄悄丢掉。

## 修复了什么

- 说“周末”“下个月”这类指代时，如果认不出具体日期，助手会先问清楚，不再默认记到今天。
- 网页端补齐内容安全策略（CSP）：内联脚本只允许页面自己那一段，被塞进来的脚本不再执行。
- 内部测试与发版流程的一批自守锁（对使用方式没有影响）。

## 优化了什么

- 切换账号后任务卡片会清空旧答案；回到同一账号时自动补读当前任务状态，不用手动刷新整页。
