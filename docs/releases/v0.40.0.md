# v0.40.0 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：安卓 `versionName` 仍是 0.36.6，检查更新按现有清单报最新可安装版本。这一版是接手后按用户六条反馈做的一轮收口：下载提速、上下文自动压缩、模型按钮挪位、模型摘要端点。

## 官网下载安卓版不再慢

- **根因不是源站慢，是源站从不肯答 304**。实测公网拉整包 7917507 字节要 8.2~12.1 秒，而本机 `127.0.0.1:8000` 只要 10~30 毫秒；响应头是 `cf-cache-status: EXPIRED`——对象就在 Cloudflare 边缘存着，但每次使用都要拿整包回源复核，而这条端点连复核都答不上。
- **修法三件**：①强 ETag 按「版本号 + 发布摘要」钉死，版本一换就换，旧包不可能被错发；②答 `If-None-Match` / `If-Modified-Since` 回 304；③磁盘那一路改用流式 `FileResponse`，天然支持 Range 断点续传与 206/416，不再整包进内存。
- 缓存头从 `no-cache` 改成 `public, max-age=0, must-revalidate`：边缘可以存，但每次使用前必须复核。**不设正数保鲜期**，所以「最新那一版 30 秒才换一次」的纪律没有被破坏。
- 304（零字节出盘）不扣「一小时 6 次」的下载额度——那一格量的是出口带宽。

## 上下文长度：界面退场，自动压缩接手

- 用户点名「上下文长度撤掉」，但同一句话里给了替代口径：「对话一长自动压缩，保留数据，保持上下文记忆」。所以退场的是**界面**，不是功能。
- **删掉**：输入卡上的上下文环、上下文账本面板、预算滑杆、「轻量整理」「恢复完整发送」两颗按钮。
- **留下并自动跑**：对话接近当前模型上限（预算的 75%）时，自动把最早几条移出**本轮发送范围**，并压成一段前情摘要挂回去。**历史原文一条不删**，往上翻仍是全文，导出仍是全文。
- **摘要由模型生成**：新增 `POST /v1/chat/summarize`，把要移出的那几条交给当前模型总结，保留用户的偏好与约束、已做的决定、未完成的事项、具体名字与数字。断网/超时/无模型时退回本地抽取式摘要——自动触发的东西必须有一条永远走得通的路。
- 这个端点**刻意无副作用**：不落会话历史、不挂附件、不记 trace。走 `/v1/chat` 的话每次压缩都会往用户历史里塞两段谁都没说过的话。

## 模型切换按钮挪到顶栏

- 模型芯片从输入卡底部搬到**顶栏标题右侧**。它原先和发送键挤在 `.input-foot` 里，一条对话里常驻占位；而它其实是很久才动一次的东西。
- 输入区现在只剩附件、提示、停止、发送。

## 网页版铺满屏幕

- `100vh` → `100dvh`：手机浏览器地址栏收起/展开时，布局视口与可视视口不一致，差的那一截就是屏底那条缝。
- 设置弹层底部补安全区内衬：手势条不再压住「关于」那组最后一行。
- 手机弹层最大高度从 `92vh` 改 `calc(100dvh - 8px)`，与 `.set-sheet` 同一口径。

## 边界与残余

- **安卓源码这轮也改了（长按语音、全面屏系统栏配色、检查更新按钮），但本版不出安装包**：`versionName` 不动，手机上仍是 0.36.6 的旧行为，要等下一次安卓发版才带上。
- **Cloudflare 侧还有一格要实测**：改了源站不等于立刻命中边缘缓存，取决于该 zone 的 Origin Cache Control 设置。上线后应确认 `cf-cache-status` 从 EXPIRED 变成 REVALIDATED、第二次请求降到亚秒、源站日志出现 304。
- 不改模型配置、用户数据、API 行为、自助注册口径与更新通道；运行期 `data/version.json` 保持原样（仍宣告 0.36.6）。
