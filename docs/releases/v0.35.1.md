# v0.35.1 更新说明

<!-- scope: server-only -->

本版只换服务端，安卓包仍是 0.35.0（不需要重新安装，也不会因此弹出新的更新提示）。

## 修复了什么

- **任务面**：管理页可以只读查看正在等你输入的任务（问题原文、进度、能否续跑、结果可见性）；首次挂起也会计入工具的频控预算；被拒绝的续跑不再扣用户自己的付费额度，另设尝试账防刷；挂起不再被审批确认端点报成执行失败。
- **安全**：网页端的续命凭据收进 httpOnly + Secure 的同源 Cookie，原生壳继续走本机加密区与请求体回落；`/health` 公开答复不再带出嵌入模型名/厂商标识；依赖改为跨平台锁文件并强制 sha256。
- **发版链**：构建前必须通过“HEAD 就是 tag、工作树干净”的预检；缺发版说明不能再被 `--allow-unreachable` 放行；换包快照按保守策略轮转；看门狗恢复增加启用读回；签名 lane 钉 Ubuntu 24.04。

## 已知事项

- 记忆后端的维度冲突（1536 维库 vs 当前 384 维）仍在，`/health` 只是把“未配置”和“真坏”分开；要恢复语义检索需要重建记忆库，见工单 #100。
- 存量网页设备在下一次输入密码后会拿到新的续命 Cookie；在此之前静默续期不可用。
