# v0.38.0 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：安卓 `versionName` 不变，官网与 App 的检查更新仍按现有清单报最新可安装版本（以 `data/version.json` 与 `/site/version.json` 为准，本说明不写死）。这一版把外部安全审计的 M-3（provider DNS 钉扎）、M-5（审批票据周期清理）与两条认证限速低危收进生产，并把 CI 的 Actions 固定到 commit SHA。

## 安全修复

- **provider `base_url` 的 DNS 钉扎**：`build_client` 在缓存 miss 时只解析一次，同一地址列表既过 `net_guard` 判闸又作为 pins 钉进 httpx 连接层；连接不再重新解析主机名，关闭“判闸→连接”的 rebinding 窗口。pin 键使用 `httpx.URL(...).raw_host`，IDN 域名不会被误判为“没有钉住”；缓存 300 秒 TTL，`trust_env=False`/`follow_redirects=False`，传输层结构变化或空 pins fail-closed。
- **审批票据周期清理**：`approval.sweep_stale()` 只删“过期超过一个 TTL”的票据，保留 confirm 后客户端轮询结果的窗口；挂到既有 5 分钟调度，不新建线程。过期票据不再在完全空闲的会话里长期留在 `data/approvals.json`。
- **bootstrap 凭据失败计数**：覆盖所有受保护路径的请求头凭据失败（不再只管理面/adopt），header 请求在解析前预占预算，堵并发突发；Cookie 通道失败也进同一账本；`_ADMIN_FAILS` 有 4096 硬上限并按最久未触碰淘汰。超限 429 + `Retry-After`，事件进 `security_log(detail=limit.admin)`。

## 供应链与运维

- **GitHub Actions 固定到 commit SHA**：四个 workflow 的 10 条 `uses:` 全部改为 40 位 SHA（保留版本注释），新增静态契约锁；不再信任可移动的 `@vN` 标签。
- **data ACL**：`data/` 目录改为显式 ACL，仅服务账户、Administrators、SYSTEM；其下已有条目显式收紧，新建/原子重写的文件继承同一三项。无 `BUILTIN\Users`/`Everyone`。这是本机运维动作，不在包内，已在 v0.37.7 之后即时生效。
- `data/config.json` 的 `registration_open=false` 与 `credit_shadow_daily_limit=1000.0` 沿用 v0.37.7 换包时的配置，本版不新增配置键。

## 边界与残余

- **没有新 APK**，本版不涉及安卓包、`versionName` 与更新通道清单。
- Cookie 通道的 bootstrap 失败计数发生在解析之后：饱和后错误答案返回 429，但常量时间比较仍会执行一次；32 位高熵口令下风险低。过期管理台 Cookie 重载会消耗同一预算，可能自锁 adopt 10 分钟。
- 同一 IP 超过 10 个并发 header 凭据请求可能被 429；只带 Cookie 的正常网页会话不经过预占。
- `trust_env=True→False` 是有意差异：依赖 `*_PROXY` 才能出网的部署会连不上；本机与服务进程当前均无代理变量。
- provider pin 的 IP 轮换最多 300 秒后才生效；TTL 替换的旧客户端不 close（等 GC）。
- 审批票的 `arguments`/`result`、MCP `args` 仍明文落 `data/`；M-7 更新清单签名、M-8 安卓凭据/通知、M-9 日志移出 `data/` 不在本版。
- CI 的 `environment:`/发布审批仍未加；本版只做 SHA 固定。
