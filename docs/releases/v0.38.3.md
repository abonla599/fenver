# v0.38.3 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：安卓 `versionName` 不变，官网与 App 的检查更新仍按现有清单报最新可安装版本。这一版把 v0.38.2 上线的官网再收一遍——首屏说清楚卖点，实拍换成与软件同色的界面，整页的编号、横带与强调色统一到一套规则，最后把仅剩的几块深色区域也收回浅色。

## 首屏与卖点

- **主次对调**：软件名回到最大一号，标语在其下；此前标语比软件名还大，读起来像两个并列的标题。
- **卖点改成一句话**：「自己的服务器，数据不出门。」长期记忆退到功能位——它是能力之一，不是这个软件的定位。
- 副文案重写为「开源的 AI 智能助手：多模型随时切换，文件丢进来就能读，要实时信息时联网查找」，把模型自选、文件、联网三件事一次说完。

## 真实界面

- **四张实拍重拍**：换成真实运行 Web 版的浅色主题截图，与官网同一套配色；此前是深色界面，贴在浅色页面上像四块黑屏。
- **删掉细节裁切墙**：`#shots` 下方那四张局部放大图在页面上始终显示不全，整块移除，四张 `detail-*.jpg` 随包退场。
- 首屏的产品示意窗同步改为浅色，与实拍一致。

## 版式与配色

- **区块头统一**：每个章节头都是通栏的品牌色横带，右端立一组 12 根信号刻度；编号压在标题上方，与标题、与下方卡片共用同一条左缘。此前编号单独占一列，把标题推离内容区左缘 180px，整块看着是歪的。
- **强调色收进一个变量**：横带、编号、刻度都从同一个颜色派生，深色主题各自取值，不再出现「横带深绿、标签薄荷」这种一条线上两种绿。
- **六张能力卡统一白底**：此前只有「多模型切换」铺淡绿底，卡内图标块还得反过来改成白色，同一套零件两种读法。
- **去掉全站深色块**：安卓专区、能力边界、开源终端、页脚行动区原先各自反色，现在是白底卡片与浅灰通栏，深色只由主题开关决定。
- 说明文字颜色回到次级灰，与正文一致；此前一段是近黑、一段是灰，同一屏里两种重心。

## 边界与残余

- **没有新 APK**：本版不涉及 `android-native/**`、安装包签名、`versionName` 与更新通道清单，`/site/version.json` 保持原样。
- 不改模型配置、用户数据、API 行为与自助注册口径；进入发布的只有官网三份资源、四张实拍、官网契约测试、更新日志产物与换包验收标记。
- 页面仍不请求外部字体、脚本或图片；深浅两套主题、桌面与手机布局、移动菜单、FAQ 与阅读进度均已实测。
- 能力边界照旧如实标注：代码执行需要宿主机 Docker（当前未开）、扫描版 PDF 需先 OCR、离线不可用。
