# v0.25.0 更新说明

## 新增了什么

- 任务与多步交办登录后就能用，不再只有管理员能使；每个人只看得到、只停得下自己的任务
- 个人用量可查：按天读到自己的调用次数与 token（只读，只回自己的，不含任何金额）
- 按模型分别设定单价的计费内核落地，本版默认关，不改变现有任何计费行为

## 优化了什么

- 点「停止」会先让服务端取消这一轮，再收掉本地显示；停下的那一轮不会再往下跑
- 流式回答带上进度序号，连接断了能接着上次的位置取回，接不上时改为从会话里取结果

## 修复了什么

- 网页版与安卓版断线后不再把整轮内容重发一遍，也就不再重复向模型付费调用一次
- 关掉页面不再让服务端继续替这次请求向模型付费：每一轮开始前先确认还有人看着
- 别人拿到任务号也探不到这个任务归谁，越权读取与不存在回的是同一句话
