# v0.23.1（真机反馈快修 · 2026-09-28 第 2 轮）

> **状态**：2026-09-28 手机实测回来四条问题，本版逐条查明原因并修掉。
> 0.23 的设备在 App 里点「检查更新」即可升级；也可以直接下载本版 APK 覆盖安装，数据不丢。

## 修了什么

- **麦克风「权限没生效」的误报**：部分厂商 ROM 上，语音识别服务会不看 App 已授权的
  权限、按自己的开关拒绝工作——你明明点了「允许」，它仍回一句权限错误，旧版据此
  把你支去系统设置，越设越糊涂。现在识别引擎重建重试后仍被拒时，改走**系统语音输入
  界面**兜底：直接在系统面板里说，识别结果照样发出去；不再让你白跑一趟设置页。
- **日程换天「先闪一下空白再出内容」**：在两个都没有安排的日子之间切换时，旧版会先
  闪一帧空白面板、再落到「这天还没有安排」。原因是加载分支把"空日子"整个收起来了。
  现在只有首次进页面才允许留白；中途换天，空态提示原地保留并置灰，新数据回来直接替换，
  不再闪。网页版同一修法。
- **提示条被拦腰截断**：状态提示以前挤在按钮行里，只有一格宽，"去系统设置…"只能看到
  「去系…」。现在提示单独占一行，最多两行完整显示，不再截字。

## 优化了什么

- **日程时间改成正经的上下滚轮**：以前的表盘指针在手机上太难瞄，改成小时/分钟两列
  滚轮——手指上下拖，数字跟着滚，中间那行就是选中的时间；确定写入，清除可留空。
  与网页端 `type="time"` 在手机上的原生滚轮手感对齐。
- **开场建议语全部换成日常话**：「总结今天的待办」这类工作汇报腔换成了
  「今天晚饭吃什么？帮我想个菜单」「帮我写条请假消息，自然一点」这种真的会问的事；
  安卓端建议从横向滑动改成自动换行铺满，每条都看得见，不用猜右边还有没有。
- **语音提示文案全部说人话**：「识别服务开了个小差，稍后再试」「没听清，再说一遍」
  「没让用麦克风，语音暂时用不了；想用的话再长按一次输入框」——不再出现
  术语和半截句子。

## 加了什么

- 本版无新页面、新能力——这是一版纯跟手性与文案的快修。

## 注意

- 网页版随服务端部署即生效，无独立发布动作；日程、语音改动双端一致。
- 数据都在服务端，覆盖安装不影响已有日程与对话。
