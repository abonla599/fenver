# v0.31.0 更新说明

## 优化了什么

- 模型调用工具收进同一条标准通道，旧的「用纯文本假装调用工具」的路径整条删除：少一种出错方式，网页版与安卓行为一致
- 审批确认卡片沿用 v0.30 状态条同一套画法与文案，双端逐字一致，不新增视觉语言

## 新增了什么

- 代码执行审批：模型想跑代码前，先弹一张「执行代码确认」卡片（网页版与 App 都有），点「允许」才执行；点「拒绝」本轮就此收手；不理会则超时作废——任何情况下都不会默认放行，没有你点头它跑不起来
- 工具护栏三件套：重复调用会被拦下、单轮工具调用设成本上限、失败的工具进入退避冷却不再被立刻重试——防止失控循环空转烧掉额度
- 工具输出预算闸：一个问题里喂给模型的工具内容总量有上限，超长搜索结果不再挤爆对话
