# v0.23.8 发布说明（2026-09-28，真机反馈第 9 轮，仅安卓原生端）

## 修了什么

- **「粘贴」气泡彻底清零**：你明确说了输入框不要粘贴，这轮照办到底。上一版想用
  "按住的时长"来拦气泡（点按拦、长按放），真机证明这台 ROM 的气泡根本不按时长
  出牌，拦不干净——这层赌博撤了。输入框改扣一层"什么都不弹"的壳：点它、长按它，
  都只干活（打字、放光标、触发按住说话），不再冒任何菜单。这层壳只扣输入框自己，
  重命名弹窗等其他地方的文字菜单不受牵连。
- **键盘和语音胶囊同屏**：挖出两条根因一起修。①键盘检测公式在这款窗口模式
  （adjustResize）下从不扳机——键盘把窗口顶扁的同时"可见区"也在缩，拿两个一起
  缩的数相减永远≈0，"键盘在就不接管语音"的门控等于没装；换成比较屏幕上的底边
  差，键盘一顶就有真读数。②长按判定瞬间单发一次"收键盘"命令，会输给键盘正在
  进行的弹出动画被吞掉；改成先收一发、随后 0.18~0.72 秒再补四发，动画结束也压得回去。
- **刚进软件长按输入框，键盘自己跑出来**：文本框手指一按下去就抢焦点把键盘顶起来
  （0.26 秒后才判出"这是长按说话"，来不及拦）。现在判定为说话后走上面的连发补刀，
  键盘冒头也就立刻被收回去，胶囊不再跟键盘并排。

## 优化了什么

- 上一版"长按输入框出粘贴/全选"的恢复项随本需求作废一并退场（你说不要粘贴了），
  输入区少一层时序赌注，行为更可预期。
- 语音模式的判定链保持第 8 轮修好的"活门控"（每次按下现取最新键盘状态），不回退。

## 加了什么

- 本版无新功能，纯修真机反馈的三件事。

## 验证方法

1. 冷启动进对话页，直接长按输入框说话 → 键盘最多闪一下就被收回，胶囊独自在场。
2. 键盘开着时长按输入框 → 不再触发语音录音（门控这回真的在查键盘）。
3. 点输入框、长按输入框 → 都不再冒「粘贴」气泡。
4. 点🎙进语音模式 → 「按住说话」照常，松手 1.6 秒兜底闹钟照常。
