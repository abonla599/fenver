# v0.36.7 更新说明

<!-- scope: android-only -->

安卓客户端这一版修用户真机反馈的三件事：长按输入框收不到声音、部分页面四角没铺满、检查更新按钮常驻占位。服务端不变。

## 修好了长按没声音

- 根因是语音接管闸把「键盘弹起」整段排除了：先点一下输入框（键盘起）再长按，这一按被交给文本框做选字——可空文本框本来就没有字可选，那道闸拦掉的只有「想说话」。现在文本框为空时长按一律归语音，键盘起没起都一样；框里有字时长按仍归选字。
- 🎙 语音模式无条件走语音。「键盘不许因长按闪现、抢焦点」的地基一个字没动。
- 新增语音自检：输入卡上出现「看看语音卡在哪」，点开逐条告诉你——设备有没有识别服务、现在用哪个引擎、本 App 麦克风授权、上次错码加一句人话解释。

## 修好了四角缝隙

- 根因不是页面没铺满，是系统栏那两条带子不是 App 画的：主题从没设置过状态栏与导航栏颜色，落到平台默认的近黑，而画布是墨绿，屏幕上下各压一条异色横带、圆角屏四角正好落在带子里。
- 现在两条栏钉成画布色，深底配浅图标，画布连续到屏幕上下两端与四角。布局一行没动。

## 检查更新按钮不再常驻

- 「检查更新」这颗按钮删掉了。进 App 或进设置时静默问一次：没新版本就只有版本号，连「已是最新版本」都不弹；有新版本这一行自己长出「发现新版本 vX.Y」，点它一步直接下载。
- 检查失败静默，不吓人；只有你主动点了才会看到一句人话原因。

## 边界

- 服务端本版不动（线上是 v0.40.0）。
- 网页版与安卓共用同一套色板令牌，官网是唯一真源；本版没有新增颜色。
