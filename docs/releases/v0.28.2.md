# v0.28.2 发布说明

## 优化了什么

- 「检查更新」基本秒回：服务端的发布信息缓存过半就先交出手里已有的一份、同时在后台补新货；服务启动后也会先把这份信息攒好，第一个人不用再替所有人去 GitHub 排队
- 打开软件的启动链路不再被慢网络卡死：模型清单、会话列表这类小请求换了一条 15 秒封顶的快线，网络抖一下会自动再试一次；生成回答与安装包下载照旧走原来的长连接线路

## 修复了什么

- 打开软件后好几分钟显示「服务端还没有可用的模型」「未配置模型」、消息发不出去：模型清单没回来之前现在如实显示「正在读取模型清单…」，这时按发送会先补拉一次清单并说清楚在读取，不再把人往「没有模型」上引
