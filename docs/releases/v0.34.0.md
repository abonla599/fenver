# v0.34.0 更新说明

## 修复了什么

- 会话到期的那一天不再会突然把人送回登录页：还剩一周时就开始自动续期，续期这条路走不通也只是这一次没续上，不会提前把当前会话弄丢
- 同一账号在多台设备上同时使用，不会因为其中一台续了期就把另一台挤下线：旧令牌还会被接受一小会儿，正在跑的请求不会中途失败
- 改密码、退出登录、被封号仍然立刻生效：这几件事会一次作废该账号所有设备上的续期凭据，旧设备不能靠它悄悄换回新会话
- 在登录框里输错密码只是这一次没登进去：不会顺带被签成一个能用的新会话，也不会因为一次输错就被记上两回失败

## 优化了什么

- 网页端现在也能免口令续上：这台浏览器登录过一次之后，即使会话走完了最长的有效期，重新打开页面仍是原来那个账号，不必再输一遍密码（用浏览器期间退出或把这个账号从设备上移除，这份能力随之清掉；升级之前就已经登录着的浏览器要重新登录一次才拿到）
- 安卓端把续期用的凭据放进系统加密存储，不再与其余设置同处明文；加密存储不可用时直接不启用这个能力，也不会退回明文保存
- 限流记账的存放位置可以整体替换：单进程部署一切照旧，若将来同一条服务多开进程，每窗口预算不再按进程数悄悄放宽；配置给错时服务会拒绝启动，而不是各记各的

## 新增了什么

- 一直用这个 App 的人不再需要重新输口令；连续 400 天没打开过的设备才需要重新登录一次
- 网页端与安卓端使用同一套续期节拍：剩余时间还多就不动、流式回答在跑就等它跑完、同一时刻只续一次、两次续期之间至少间隔六小时
- **没重新登录过的设备暂时拿不到这个能力**：续期凭据只在注册、登录、重新登录这三处下发，升级后请在这台设备上登录一次
