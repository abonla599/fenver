# v0.29.2 更新说明

## 修复了什么

- 安卓端的回复里不再出现成对的星号：模型按 Markdown 写的加粗，此前在原生界面是把 `**文字**` 原样上屏的，现在渲染成粗体；代码块里的星号仍然原样保留，复制出来的代码不带多余的 `**`
- 思考过程边想边上屏：此前模型只想不说的那段时间里，面板一个字节都不动，思考文本和答案会一起冒出来；现在思考、工具调用、搜索命中在发生的那一刻就送上网，网页端与安卓端同时受益
- 只更新服务端即可生效：旧版客户端不需要重装也能看到思考过程逐段出现（帧本来就是它认得的那几种，只是过去迟迟收不到）

## 优化了什么

- 安卓端的过程面板长高时列表会跟着走到底部：想看它想到哪一步，不用手动下滑；正在上翻阅读历史时不会被拽回去
