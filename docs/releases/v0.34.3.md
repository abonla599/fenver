# v0.34.3 更新说明

<!-- scope: server-only -->

本版只换服务端，安卓包仍是 0.34.2（不需要重新安装，也不会因此弹出新的更新提示）。

## 修复了什么

- 不用登录就能读的那几面服务器自述——它报自己健康状况时关于记忆的那一条，还有手机上「检查更新」得到的答复——出故障时以前会把这台机器上的文件夹位置连用户名一起、连同它用的是哪家的模型，一并写进公开答复里。现在公开答复只留下判断所需的数字，文件夹位置那类细节改记在服务器自己的日志里，不再跟着答复外发。
- 把一段执行记录补发给不属于它的那个人时，其中「这一步要不要批准」那一条以前会带着动作的名字和当时的参数原文，出现在别人的界面上。现在这一条也一并遮掉了，各人看到的仍是自己那一面。

## 优化了什么

- 一批改动只落在测试与构建环节，装在手机上和网页上能做的事都不变。
