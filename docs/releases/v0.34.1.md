# v0.34.1 更新说明

<!-- scope: server-only -->

本版只换服务端，安卓包仍是 0.34.0（不需要重新安装，也不会因此弹出新的更新提示）。

## 修复了什么

- 网页版地址栏里那一段本来只用来对版本的参数，不再被原样搬进页面内容里。以前有人构造一条带引号的链接、再让一个已经登录的人点开它，页面里可能多出他写的那一段；现在这一段只接受纯数字，任何别的形状一律改用服务器自己算出来的那一份。同一处改写还覆盖后台那个负责"改版后自己好回来"的文件。
- 发给手机的安装包下载地址，现在只可能是我们自己的那两个域名之一。以前它跟着访客自己写来的主机名走——手机那侧本来也会把对不上校验值的包拒掉，所以不会装成别家的东西，但"只许落在自家域名上"这句原本只写在说明里、没写进代码，这次把说明和实现收成同一件事。

## 优化了什么

- 安卓构建自己攒下来的那份本地缓存不再会被误提交进公开仓库（它里面是二进制哈希库，且每构建一遍就换一遍，会让"工作区干净"这条发版判据失去意义）。
