# v0.36.4 更新说明

本版同时更新服务端与安卓安装包：安卓包版本 0.36.4（versionCode 69），native 代码与 0.36.1 相同；服务端 build 同为 0.36.4，带上管理台安全页的攻击可视化增强。

## 修复了什么

- 手机端「检查更新」一直显示 0.36.1：安卓包版本号改为 0.36.4（versionCode 69），与更新清单一致。安装包与 0.36.1 使用同一证书（v2-only、单签名者），可直接覆盖安装，无需卸载。

## 优化了什么

- 安全页顶部先用一句人话总结窗口内的攻击：次数、主要来源、主要目标账号与高危数量，附级别说明。
- 严重度分布：一条横向堆叠条显示高危 / 警告 / 提示的占比，附图例与百分比。
- 攻击时间线：1 小时 12 个 5 分钟桶、24 小时 24 个小时桶、7 天 7 个天桶；柱高表示事件量，含高危的桶用危险色。
- 事件原因：登录失败、注册/重置被拒、reauth 被拒、登录/注册/重置/reauth/聊天/编排限流、令牌无效、CSRF 缺失等枚举翻成中文，未知值原样显示。
- 严重度筛选：全部级别 / 高危 / 警告 / 提示，与类型、来源、账号筛选组合使用。
- 来源指纹：来源前缀后附 8 位指纹，便于区分同一网段的不同来源；页面仍不显示原始 IP。
- 更新清单 /v1/update/info 与 /site/version.json 宣告 0.36.4：APK fenver-0.36.4.apk，size 7,847,523 B，sha256 e712ed6b09c303d5ccb9a6fd08d65d1a82fe444d6c58e5ce9a798ccf8f1bd488。
- 保留 v0.36.3 的五分区、账号管理、反馈截图缩略图与页内放大、运行区六子页与安全日志。

## 新增了什么

- 风险横幅：窗口内出现高危事件时标红「检测到 N 条高危事件，建议优先处理」；没有高危时显示安全态。
- 攻击类型排行：与攻击来源 Top、涉及账号 Top 并列，直接看窗口内主要是哪类攻击。
