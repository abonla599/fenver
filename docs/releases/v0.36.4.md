# v0.36.4 更新说明

本版同时更新服务端与安卓安装包：安卓包把版本号顶到 0.36.4（versionCode 69），native 代码与 0.36.1 相同，用于让手机端检查更新能收到新版本；服务端带上管理台安全页的攻击可视化增强。可直接覆盖安装，无需卸载。

## 管理台安全页

- **风险横幅**：窗口内出现高危事件时直接标红「检测到 N 条高危事件，建议优先处理」；没有高危时显示安全态。
- **严重度分布**：一条横向堆叠条显示高危 / 警告 / 提示的占比，附图例与百分比。
- **攻击时间线**：按窗口自动分桶（1 小时 12 个 5 分钟桶、24 小时 24 个小时桶、7 天 7 个天桶），柱高表示事件量，含高危的桶用危险色。
- **攻击类型排行**：与攻击来源 Top、涉及账号 Top 并列，直接看窗口内主要是哪类攻击。
- **事件原因**：登录失败、注册/重置被拒、reauth 被拒、登录/注册/重置/reauth/聊天/编排限流、令牌无效、CSRF 缺失等枚举翻成中文，未知值原样显示。
- **严重度筛选**：全部级别 / 高危 / 警告 / 提示，与类型、来源、账号筛选组合使用。
- **来源指纹**：来源前缀后附 8 位指纹，便于区分同一网段的不同来源；页面仍不显示原始 IP。
- 保留 v0.36.3 的五分区、账号管理、反馈截图缩略图/放大、运行区六子页与安全日志。

## 已知限制

- 安全事件当前覆盖鉴权与中间件；工具、审批、供应商事件留待后续版本。
- 时间线只对 1h / 24h / 7d 三档有固定桶宽；其它窗口值不属于公开契约。
- 真机覆盖安装、移动端布局与 20 秒自动刷新仍需设备侧确认。
- 本版不包含 v0.37 的 http_fetch / MCP。
