# v0.23.4（语音入口点名 + 输入栏按钮自设计图标）

> **状态**：2026-09-28 第 5 轮真机反馈快修版。本版只动安卓原生端，网页版无改动。

## 加了什么

- **「去给「某某App」开麦克风」点名入口**：上次那个红字提示说的"语音服务"，是手机里
  另一个 App（比如语音助手/语音搜索）自己的麦克风授权——不是本 App「AI 助手」的。
  现在按钮直接把那个 App 的名字写在脸上，点一下跳到它的系统设置页，不会再开错地方。
  认不出目标时也会把手机上所有语音识别服务列出来挨个试。
- **「用系统语音输入试试」备用通路**：一键调起手机自带的语音输入界面（在你手机上
  手动点才弹，绝不自动跳出来吓人），认出字来直接发送。就算识别服务一直修不好，
  这条路也能先把话说了。

## 优化了什么

- **输入栏按钮全部换成自绘线性图标**：相机、麦克风、键盘、加号、发送箭头、停止、
  图片、文件、菜单——不再是 emoji 字形。统一 24 格网格、圆头描边；按下去有轻微
  缩放回弹；发送钮是渐变圆底加一圈品牌色光晕；语音模式下的麦克风钮变主色实心、
  图标换成键盘，一眼看得出当前是哪种模式。附件面板和消息附件条也同步换装。

## 修了什么

- **「语音权限明明打开了还是不行」**：你截图里开的是本 App「AI 助手」自己的麦克风
  （它早就是通的），真正拒录音的是语音服务那个 App。本版把入口点名、把目标 App
  的设置页一跳直达，并加了上面那条系统语音输入备用通路。
- **找不到语音服务时入口直接消失**：上一版跳设置页的按钮依赖系统"默认识别服务"
  查询，部分手机上查不到就整个不显示。现在查不到就枚举全部候选服务兜底。

## 注意

- 覆盖安装即可，数据不丢。
- 语音修复步骤：长按或点麦克风说话 → 出现「去给「××」开麦克风」→ 点它 →
  在系统页里给那个 App 开麦克风 → 回到 App 再按住说一次（每次都会自动重连识别服务）。
- 装好后如果输入栏按钮样式仍不满意，截图圈出来，继续调。
