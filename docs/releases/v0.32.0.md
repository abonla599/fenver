# v0.32.0 更新说明

## 修复了什么

- 联网搜索不再会因为源站改版而悄悄失灵：搜索从单一来源升级为可降级链条，前一个源给不出结果就自动换下一个，并且每次回答旁都写明这次用的是谁

## 优化了什么

- 管理页新增「搜索用量」：这周搜索跑了几次、挂在哪个源各几次、每个源的成功率，一眼能看到；没配密钥的源如实显示未启用，不与失败混在一起
- 网页版与安卓的搜索步骤标题统一为「搜索：关键词 · 来自 博查/Tavily/必应」，双端逐字一致；历史会话里旧的搜索步展示不受影响

## 新增了什么

- 搜索源密钥配置：管理员可在管理页登记博查/Tavily 的搜索密钥（填与看都只有末四位，明文不落盘不进日志），填上即切主源、无需重启；不填则与之前行为完全一致
- 自带密钥的设备本机直连：网页版与安卓设置页新增「搜索源」面板，你自己的密钥只保存在你这台设备上、只用于你的浏览器直接向搜索源发请求，数据不经本站中转；真机验证页同步新增搜索直连探测项
- 搜索结果引用上屏：回答里的联网来源以「N 个网页」列表可见，点标题直达原站核对，网页版与 App 展示一致，方便你验证每条说法的出处
