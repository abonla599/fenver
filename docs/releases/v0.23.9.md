# v0.23.9 发布说明（2026-09-29，真机反馈第 10 轮，仅安卓原生端）

## 修了什么

- **键盘"闪一下"根治**：上一版的做法是手指按下、文本框抢焦点把键盘顶起来，
  0.26 秒后判出"这是长按说话"再把键盘摁回去——收得再快也是闪一下，这层被你
  判死。这轮换成源头根治：长按闸门在位的那段时间里，输入位渲染的是一块
  "发消息或按住说话…"占位条，文本框压根不挂载。没有文本框就没有焦点可抢，
  键盘全程无从出现——长按说话时一次都不会闪。
- **语音 UI 就地取代输入框（学豆包/DeepSeek）**：松手录音时不再有漂浮在屏幕上
  的第二块"胶囊屏"，录音条直接躺进输入框原来的位置：左麦克风呼吸点、中间
  "正在听你说…/松开手指就取消"加实时识别大字、右侧收窄版音量波纹，上滑取消
  整条转珊瑚色。说完松手，字从这条里出去，输入位恢复原样。

## 优化了什么

- **点按=打字，长按=说话，各走各的**：轻点占位条（没到长按判定线就抬手）=
  想打字——文本框当场挂回、自动聚焦、键盘随松手出现；按住不放=说话——键盘
  全程不出现。跟豆包/DeepSeek 的手感对齐。
- 旧版"先顶起键盘再连发补刀收回去"的机制原地保留为双保险，只防极窄的重组
  间隙；主责换成"不挂框"，不再依赖时序赌注。
- 第 3~9 轮修好的东西全部保持：活门控、松手 1.6 秒兜底闹钟、输入框无粘贴
  气泡、点名开麦/换引擎入口、深浅双主题配色。

## 加了什么

- voiceHold 手势状态机新增"短按"出口：按下被语音闸门一口吃掉，抬手没到判定
  线就走短按回调，输入栏据此决定是挂回文本框请键盘，事件不再两头漏。

## 验证方法

1. 冷进对话页直接长按输入框说话 → 键盘从头到尾不出现，录音条就地替换输入位。
2. 轻点输入框 → 松手后键盘才出现，正常打字。
3. 长按后上滑再松手 → 录音条转珊瑚色提示"松开手指就取消"，取消不发送。
4. 边说边看：识别中的字实时显示在录音条里；说完松手自动发送。
