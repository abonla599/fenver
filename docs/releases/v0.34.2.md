# v0.34.2 更新说明

## 修复了什么

- 填模型服务地址时，现在会先查这个名字真正指向哪里再决定收不收：一个看着像公网的域名，只要它的记录落到本机、内网或云主机的元数据地址上就一律拒，连名字都查不出结果的也拒。以前只看名字像不像外网，这类地址会被收下，此后每一次对话都会把你的密钥送到那台机器上
- 上传文件的记录里如果出现被人改过或坏掉的路径，四个出口一律把那条记录当成不存在：不会再去读那个目录之外的文件，不会把目录之外的内容拼进对话或送给模型，也不会删掉它；磁盘一字节不动，那条记录本身留着当"有人动过索引"的证据
- 一轮对话的 token 总额到上限时，现在真的会把后面的工具停下来；以前那句"请基于已有结果直接回答"发得出去，工具却一个都没停，上限跳过之后照样继续调用、继续花钱
- 官网更新日志的头条以前会播出一个装不上的版本号（只换服务端、没有安装包的那一版），点下载却仍是上一版；现在头条只播有安卓安装包的那一版，只换服务端的那些收进独立分栏，内容一条都没有删
- 换包的验收以前只数新包里有没有那句版本标记，从来不数正在跑的包里有没有；两次"只换服务端"的换包因此都打印了绿色却什么都没证明。现在两侧都数，装机的包里也能读到这条标记就当场拦下；确实要往回退时必须同时给出回退证据，否则脚本拒绝执行
- 安装部署指南里那条安卓出包命令指的是已经删掉的旧目录，照着敲只会得到"目录不存在"；现在写的是真正在跑的那一条，并注明托管出包那条链路当前不通、现行路线是本机出包

## 优化了什么

- 手机上的「设置 → 关于 → 版本」这一行现在只有一个号码：这台设备上能装能跑的那一版。以前是"壳 v0.34.0 · 服务端 v0.34.1"两个数并排，后面那个长得像一个你能安装的版本，但它装不到手机上；能装的是哪一版仍由紧挨着的下面那一行「检查更新」告诉你
