# v0.36.2 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：官网与 App 的检查更新仍会告诉你最新可安装版本是 0.36.1（versionName 保持 0.36.1）。这一版收两件事：嵌入密钥单源化，和更新通道来源判定的 Host 白名单。

## 修复了什么

- **嵌入密钥单源**：记忆模块的嵌入密钥改以「设置 → 模型服务」里的 provider 配置为唯一来源，`.env` 只留一枚非密钥的指针 `EMBEDDINGS_PROVIDER_ID`（指向哪条 provider）。过渡期仍兼容旧的 `.env` `api_key`：指针指不到可用密钥时会回落到它并在日志里响亮提醒；两边都没有才降级本地/伪嵌入。**改完或删掉那条 provider 配置需要重启服务才生效**（没有运行期热加载）。运维删除 `.env` 里旧 `api_key` 之前，必须先配上指针并确认 `/health` 的记忆后端是"云端嵌入"——现网记忆库按既定维度建库，指针失效落到伪嵌入会触发维度冲突、记忆接口 503。
- **更新通道 `_self_origin` 收口**：`/v1/update/info` 用来拼"发给手机的下载地址"的来源判定，现在自己就把门守死——Host 去掉端口/userinfo/路径段后，小写必须落在自家域白名单（ai.fenever.xyz / www.fenever.xyz）之内；`X-Forwarded-Proto` 只有**可信对端**（本机回环，或显式配置 `SELF_TRUSTED_PROXIES` 的 IP/CIDR 清单）说的话才采信，不可信对端一律不换下载地址。原先这层判断全部押在下游那把域闸上，本版是把它补成纵深防御，下游行为一字未动。

## 说明

- 接口形状、安卓端代码、官网页面均无变化；覆盖安装与日常使用不受影响。
- 管理员侧无新增操作要求；本轮发版会在服务端先完成"指针上线 → 验证 → 摘除旧 `api_key`"的切换。
