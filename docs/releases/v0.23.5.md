# v0.23.5 本版变更（2026-09-28，真机反馈第 6 轮快修，仅安卓原生端）

装法：直接覆盖安装，不用卸载旧版（0.23.3 / 0.23.4 均可直升）。

## 加了什么

- **「换个语音引擎」**：输入栏修复行第一位的新按钮。点开列出手机上**所有**能
  做语音识别的引擎，选哪个就用哪个，下次开机还记得你选过谁。
- **自动轮换**：如果你没手动选过引擎，而当前引擎连着两次「连不上它自己的
  服务器」，App 会自动换到下一个候选引擎并告诉你换到了谁——再按住说一句就行。
- **系统语音设置直达**：引擎弹窗里给了一行「打开系统语音设置」，个别手机上
  默认引擎要在系统层面换，从这里进去改。

## 优化了什么

- **错误提示说人话**：「语音识别没成功（11）」这种机器码，现在换成一句能行动的
  话：是谁连不上服务器、开麦克风没用、下一步点哪个按钮。备用通路（用系统语音
  输入试试）失败后的提示也改了口径——它和长按用的是同一个引擎，不再误导你
  去开麦克风。

## 修了什么

- **长按闪一下蓝色穹顶就报 11**：真机查明这是 ERROR_SERVER_TERMINATED——你手机上
  的默认引擎「系统语音引擎」连不上**它自己的**识别服务器（它的识别要回它家的云
  端做，国内网络到不了）。这不是权限问题，所以第 5 轮的「去开麦克风」按钮治不了
  它。现在 App 认得这类错误，直接引导/自动切换到能用的引擎。
- **白框「似乎出错了呢 (2)」**：那是那个引擎自己弹的错误窗（它弹的，不是本助手
  弹的），根因同上，换引擎后不会再出现。

## 注意

- 修复步骤：装上 0.23.5 → 按住说话失败一次 → 点输入栏下方的「换个语音引擎」→
  选一个非「系统语音引擎」的候选（比如手机厂商自带的语音服务）→ 再按住说一句。
- 如果弹窗里只有「跟随系统默认」一个选项，说明手机上只装了一个识别引擎：
  去「设置 → 应用管理」确认厂商语音服务有没有被停用，或安装一个第三方语音
  输入法/语音服务后再试。
- 本版无网页端改动。
- 装好后如果还有问题，把状态条那行字截图发回来，上面写着引擎名和错码，一看就知道卡在哪。
