# v0.23.6 发布说明（2026-09-28，真机反馈第 7 轮，仅安卓原生端）

## 加了什么

- **原创「语音胶囊」浮层**：按住说话的界面不再照搬微信的蓝穹顶，换成自家风格——
  贴底悬浮的深玻璃圆角卡，品牌绿细描边，卡里是随音量呼吸的麦克风圆点、实时识别
  大字和染了品牌色的波纹条；上滑取消整张卡转珊瑚色。深浅两套主题各配各的底色，
  背景只压一层薄雾不再黑屏。
- **松手兜底闹钟**：松手等识别结果最多等 1.6 秒。引擎到点不回包也强制收尾——
  说过话就按半截识别文字发出去，一个字没说就安静收起，绝不再把录音界面挂在屏上。

## 修了什么

- **键盘开着长按出不了「粘贴」**：第 4 轮为了赶跑一枚关不掉的粘贴气泡，把整个
  文字工具条换成了空壳，副作用是键盘弹着长按输入框什么都出不来、想粘贴没门。
  本轮把空壳整块拆掉，恢复系统默认的「全选/粘贴/选择」工具条；长按语音的门控
  本来就在（键盘在=不接管），两件事从此互不打架。
- **没说话松手，蓝色穹顶永远不消失**：根因是有的识别引擎在"松手等结果"阶段
  既不回结果也不回错误，界面状态就挂死了。换成胶囊浮层的同时，在识别器内部
  装了超时兜底（见上），卡死路径整条焊死。

## 优化了什么

- 录音中没出声时，胶囊里显示「说点什么，松手发送」占位提示，一眼知道现在该干嘛；
- 松手后没听到任何声音时给一句「没听到说话，这次先不收」，不再无声消失让人
  以为发出去了。

## 注意

- 本版只改安卓原生端，网页端无变化（`version.txt` 仍 v0.23.2，属预期）。
- 覆盖安装即可（0.23.4 / 0.23.5 直接升，登录与聊天记录保留）。
- 验证：①点输入框唤起键盘 → 长按输入框 → 应浮出「全选/粘贴/选择」工具条；
  ②收起键盘长按输入框 → 出「语音胶囊」→ 不说话直接松手 → 约 1.6 秒内胶囊收起；
  ③说半句松手，若引擎不回最终结果，识别到的半截字会自动发出。
