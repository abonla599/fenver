# v0.24.0 更新说明

## 新增了什么

- **开源**：源码搬到 https://github.com/abonla599/fenver ，Apache-2.0 许可
- **账号自助闭环**：用户名、密码和三道找回题都由本人填；忘记密码答对三道题就地设新密码，
  不用找任何人；换手机用同一个用户名再登录一次就行
- **管理端账号管理**：建号、重置密码、强制下次登录改密、禁用与解禁，都在管理页里做；
  注册开关也在这一页，默认关闭（平时只由管理端建号）
- **操作留痕**：管理端每一次改动记一条，谁改的、改了谁、什么时候
- **设置 → 关于**：网页与安卓各补上同一套三句——项目定位、开源仓库、许可证

## 优化了什么

- 安卓更新包改用新名字 `fenver-<版本>.apk`；同一版并挂一份旧名
  `ai-assistant-native-<版本>.apk`，字节完全相同，给按旧名字找包的老版本继续找
- 装完遗留的安装包冷启动自动清掉，两种名字留下的那一份都清
