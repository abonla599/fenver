# v0.36.0 更新说明

<!-- scope: installer -->

本版有安卓包（0.36.0），服务端与网页端同版更新。覆盖安装保留账号和本地数据。

## 优化了什么

- **界面**：App 与官网/网页版统一为极简原生风格：中性表面、单强调色、发丝线和更清晰的层级，弱化渐变、光晕和模糊。
- **设置与会话**：打开设置与会话抽屉直接显示已加载内容；页面与弹层切换更利落。
- **聊天**：长回复、流式输出和附件图片的滚动与输入更顺，列表与渲染做了缓存。
- **图标**：桌面图标换成更简洁的“气泡 + 星芒”，支持 Android 13 主题图标。
- 安卓包版本 0.36.0；覆盖安装即可，不需要卸载；接口形状未变。
