# v0.36.1 更新说明

<!-- scope: installer -->

本版有安卓包（0.36.1），服务端与网页端同版更新。覆盖安装保留账号和本地数据。

## 优化了什么

- **首帧不再空白**：设置页、模型服务页、记忆页打开即显示已读到的缓存内容，模型与记忆两路数据并行拉取，不再停在空白或"读取中"。
- **会话切换**：切换会话改成"挤入卡片"动效；切会话时旧会话的流式回答不再落到新会话里，旧会话的慢回包会被丢弃。
- **图标**：App 与官网/网页设置页换成一套原创图标语言（24 格网、1.8 描边、切角/折角签名）；外观行图标由太阳改为月牙，提醒由铃改为旗，服务地址由地球改为靶心。
- **模型服务列表**：移除不可用的"Qwen 视觉"占位项（运行时数据清理，非代码功能）。
- 安卓包版本 0.36.1；覆盖安装即可，不需要卸载；接口形状未变。
