# v0.36.6 更新说明

<!-- scope: android-only -->

安卓客户端的设置页把版本与检查更新合成一行，更新各态的号码只出现在带标签的提示里。本版只出安卓包，服务端不变。

## 优化了什么

- 「版本」行只留本机已装的那一个号码，检查入口改成同一行里的「检查更新」小胶囊。
- 独立的「检查更新」行删除，设置页少一行重复入口。
- 检查中、已是最新、检查失败三态改走顶部提示；发现新版本时弹带「发现新版本」标签的对话框，通道里那一版的号码只出现在这个标题里，下载与安装沿用原有弹层。

## 修复了什么

- 「已是最新版本」提示不再附带通道版本号：回滚到旧版时那个号码会比版本行显示的更小，两个号对不上。
