# v0.29.0 更新说明

## 新增了什么

- 回答上方新增「思考过程」面板：模型在想什么、这一步要调哪个工具（名称、参数、结果、耗时）、搜索时命中了哪些网页（标题、摘要、可点开的链接），在回答还在往下写的时候一条条实时出现，网页版与安卓版同一套
- 面板在生成过程中展开，回答落定后自动折叠成一行，点一下可以再展开核对来源；刷新页面或重开这个会话，这一轮的过程还在，不跟着正文一起被压回一句话
- 过程很长时不会悄悄裁掉：中间被省略的部分明说成「…中间 N 步已省略…」，并且先保住工具调用与搜索命中那几条，被裁的优先是大段思考
- 思考那一栏只有模型自己肯给出的情况下才有（如 deepseek-reasoner、开思考模式的通义千问）：换成不输出思考过程的模型，界面上就少这一栏，不会凭空补一段看着像思考的字
- 流断之后改走非流式那次兜底时，过程面板仍有工具调用与搜索命中，但没有思考文本

## 优化了什么

- 搜索到的网址现在从回答里独立出来摆在过程面板上，可以直接点开核对；此前这些来源只进过给模型看的那段文字，用完就没了
