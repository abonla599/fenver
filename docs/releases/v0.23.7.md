# v0.23.7 发布说明（2026-09-28，真机反馈第 8 轮，仅安卓原生端）

## 修了什么

- **点一下输入框就冒「粘贴」气泡**：第 7 轮为了找回长按粘贴，把文字工具条整个
  换回系统默认，结果这台 ROM「短按也请菜单」的老毛病跟着复发。这次不再一刀切：
  默认工具条外面包一层"按时长把关"的壳——短按（抬起不足 0.3 秒）请来的菜单直接
  吞掉；手指还按着的长按（超 0.3 秒）原样放行，「粘贴/全选/选择」一个不少。
  点输入框从此只出键盘，不再弹气泡。
- **键盘弹着还能触发语音、胶囊和键盘同屏**：挖到第 4~8 轮反复复发的真根因——
  长按门控的协程不随界面重组刷新，手里那份"键盘弹没弹"的状态永远冻在第一次
  画界面时的 false，所以"键盘在=不接管语音"这条规矩在真机上从来没生效过。
  改用 rememberUpdatedState 每次按下现取最新状态，门控从此是真的在查键盘。
  另加双保险：长按判定为说话的那一瞬间，先命令窗口控制器把键盘压下去再开录音
  （clearFocus 在这台 ROM 上收不了键盘，实测必须 hide(ime)），语音胶囊和键盘
  从此不同屏。

## 加了什么

- 语音模式开关键切换时同样走实收键盘（hide ime），点🎙进语音模式后键盘保证收干净，
  「按住说话」大按钮独占输入区。

## 优化了什么

- 粘贴气泡的治理范围收窄到输入框自己那一块：消息正文、设置页等其他文字的长按
  菜单完全不受牵连，不再像第 4 轮那样整屏罩掉。

## 注意

- 本版只改安卓原生端，网页端无变化（`version.txt` 仍 v0.23.2，属预期）。
- 覆盖安装即可（0.23.5 / 0.23.6 直接升，登录与聊天记录保留）。
- 验证：①点输入框 → 只出键盘，不冒「粘贴」气泡；②键盘开着长按输入框 → 照样
  浮出「粘贴/全选/选择」；③收起键盘长按输入框 → 语音胶囊出现时键盘保证收起，
  不再同屏；④点🎙进语音模式 → 键盘立即收起，「按住说话」可用。
