# v0.36.5 更新说明

安卓客户端的界面换成与官网同一套墨绿设计，功能与操作方式不变。

## 优化了什么

- 配色从近黑改成官网的墨绿：底色、卡片、描边、文字、强调色与危险色全部同源。
- 字体族、字号阶梯、圆角档位、阴影、标题字重与官网一致。
- 侧栏与留白铺上官网那层细网点，聊天卡片和消息气泡仍是实色表面。
- 次要文字在更亮的卡片上提到更清楚的一档，说明、输入提示、表头与空态不再发灰。
- 深浅外观切换取消。安卓、网页版与官网现在都是同一套单主题配色。
- 官网色板成为三端唯一的取值来源，以后改配色不会只改到其中一端。

## 修复了什么

- 设置页部分说明文字在墨绿卡片上对比度不足。
- 资源注释导致的安卓构建中断。
