# v0.38.4 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：安卓 `versionName` 仍是 0.36.4，检查更新按现有清单报最新可安装版本。内容把 v0.38.3 之后官网攒下的整轮改版一次发出——配色从浅色换回墨绿单主题，首屏标题回到品牌名、正文改说价值，新增「不一样的地方」一节，全站文案逐句重写过。

## 首屏

- **标题回到品牌名**：v0.38.3 那版标语比软件名还大，读起来像两个并列的标题。现在最大一号是「Fenver」，那句话退到它下面。
- **正文改说价值**：原来写「数据留在你自己的服务器上」——那是部署事实，读者看完只知道"它装在你家"，不知道为什么用它。现在是一句「用得越久越顺手。」，说的是记忆攒下来这件事；它也是这个软件和一次性问答的分界。
- **三个能力仍在**：模型自选、文件可读、随问随查，收成一行放在价值句下面。
- 导航右侧标签从 `SELF-HOSTED` 换成 `PERSONAL ASSISTANT`：这一格该说"这是什么"，不是"怎么部署"。

## 新增「不一样的地方」

原来整页只有"它能做什么"，没有"凭什么选它"——六张功能卡里有一半是任何 AI 都有的。这一节三条，每条底下挂一句"别处怎么做"的小字注脚：

- **记得住，也攒得下**——偏好、习惯、正在跟进的事说过一次就留下；日程和对话用的是同一份记忆。
- **办到一半会回来问**——要分几步的事交给它，走到需要你拍板的地方停下来等，回一句它接着跑。
- **换模型不换脑子**——今天用这家明天换那家，记忆、会话、日程都留在原地。

## 配色与版式

- **回到单主题深色**：底色 `#2b3d34`（偏绿的墨，不是黑），全站一套配色，去掉深浅切换与 `themeBtn`，`site.js` 里对应的主题逻辑一并删掉。v0.38.3 那版是浅色，两种都试过，现在留深色这一套。
- **底色铺一层网点**：32px 一格、1px、8% 不透明度，内联 SVG data URI。不用渐变——官网契约明文禁止 `gradient` 出现在样式表里。
- **首屏一道环**：直径 980px，被首屏上下边切掉，只留左右两段弧。靠 `.hero { isolation: isolate }` 才能浮在底色之上。
- **首屏改居中单列**：原来 `hero-grid` 是左右分栏。
- **区块头统一居中**：编号压在标题上方，与标题、下方卡片共用同一条左缘。
- 品牌图标换成与软件同源那一枚（闭合框右上角切角 + 3 节点 trace）。

## 文案

全站逐句重写过，去的是四类毛病：对偶四句、否定排比、说教式对比、每句都是"主谓宾加句号"的电报体。句子改短了，但留了语气——不是把话切成电报。

## 边界与残余

- **没有新 APK**：不涉及 `android-native/**`、安装包签名、`versionName` 与更新通道；`/site/version.json` 保持原样（包内那份仍指向 0.36.4）。
- 不改模型配置、用户数据、API 行为与自助注册口径；进入发布的只有官网四份资源与官网契约测试。
- 页面仍不请求外部字体、脚本或图片；CSP 的 `img-src` 本来就含 `data:`，网点与环都是内联 SVG。
- 能力边界照旧如实标注：代码执行需要宿主机 Docker（当前未开）、扫描版 PDF 需先 OCR、离线不可用。
- **应用内文案不在本版**：网页版 App 那批去 AI 腔的改动留在 develop，等下一版和安卓一起发。
