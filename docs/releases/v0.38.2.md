# v0.38.2 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：安卓 `versionName` 不变，官网与 App 的检查更新仍按现有清单报最新可安装版本。本版把官网升级为与软件同源的产品化设计，并完善桌面与手机端浏览体验；不包含 `develop` 上尚未发布的 M-7、M-8 或 H-1 安全开发提交。

## 官网重设计

- **首屏产品化**：用对话、长期记忆与联网搜索场景说明产品价值，网页版与安卓版入口保持一眼可见；首屏展示区使用浅灰绿画布，只保留手机界面本身的深色。
- **统一软件视觉语言**：沿用中性表面、薄荷绿主色与少量 AI 紫，重做导航、能力卡片、安卓专区、真实截图墙、开源区、常见问题与页脚。
- **真实功能与证据**：保留现有下载端点、能力边界、开源注册口径和纯文字仓库地址；四张当前 Web 版实拍与四张细节裁切全部随包发布，仍不依赖外部字体、脚本或图片。
- **响应式与交互**：桌面与手机布局、移动菜单、深浅主题切换、FAQ、阅读进度与复制链接均完成实测；更新日志长文本可换行，不再撑宽手机页面。

## 边界与残余

- **没有新 APK**：本版不涉及 `android-native/**`、安装包签名、`versionName` 或更新通道清单。
- 本版不改模型配置、用户数据、API 行为与自助注册口径；仅官网资源、官网契约测试、更新日志产物与换包验收标记进入发布。
- 官网仍如实标注代码执行、扫描版 PDF 与离线使用的当前边界，不把尚未开启的能力写成现成功能。
