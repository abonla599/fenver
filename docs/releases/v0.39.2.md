# v0.39.2 更新说明

<!-- scope: server-only -->

本版只换服务端，**没有新的安卓包**：安卓 `versionName` 仍是 0.36.4，检查更新按现有清单报最新可安装版本。线上此前是 v0.39.1（模型驾驶舱），这一版把「界面与官网统一」落到网页版 App 与管理台：整套配色、字体、圆角、组件形态和视觉调性改用官网那一套墨绿单主题，官网的色板同时成为三端唯一的取值来源。功能与交互一律没动，唯一的例外是下面写明的「外观」切换被移除。

## 界面换成官网那一套

- **墨绿单主题**：底色从近黑 `#0a0b0e` 换成官网的 `#2b3d34`，表面、描边、文字、主色、AI 紫、危险色全部换成官网 `:root` 的值。侧栏与留白处铺上官网那层 32px 网点（内联 SVG，不引外链）；聊天卡片与气泡仍是实色表面，正文不受影响。
- **字体排版**：改用官网同一套系统字体族、`clamp()` 字号阶梯、1.68 行高、标题 700 字重与数字等宽。字号随窗口宽度收放，1440 / 768 / 390 三档分别是 16.96 / 16.58 / 15.82px。
- **组件与形状**：圆角收进官网的 10 / 14 / 24 / 胶囊四档，阴影、焦点圈、选中态同档；原先散落在 CSS 里的 43 处固定圆角与一批硬编码色值全部收口到令牌。录音浮层的两道装饰性渐变换成官网 AI 紫与危险色的实色表面（驾驶舱那圈环形进度用的是 conic-gradient，是进度本身，保留）。
- **管理台同源**：管理台继续只读 `/app/style.css` 那一份设计系统，不再自留第二套色板或字体栈。
- **小字对比度**：官网的 `--ink-faint` 是按页面底色 `#2b3d34` 调的，直接放到应用更亮的卡片上只有 3.5~4:1。本版把「要读的」次要文字——说明、输入占位符、表单提示、表头、空态——升到官网 `--ink-soft`，实测 4.76 / 5.44 : 1；分组标签、时间戳这类装饰性弱化元素维持原档，层次不丢。

## 单主题

- 设置里「外观」那一行与深浅切换一并移除：官网是单主题，应用不该有第二套配色。浏览器与系统 UI 的 `theme-color` 钉成 `#2b3d34`，不再跟随系统明暗、不再存主题偏好。
- **这是本版唯一改动交互的地方**。除此之外的登录、注册、找回、会话、消息、模型、日程、任务、反馈、管理端操作与全部 API 行为原样。

## 色板只有一份真源

- 官网 `site/site.css` 的 `:root` 是权威，网页版的 `--fv-*` 与安卓 `FenverTokens` 逐字对齐它。
- 契约测试 `test_design_tokens_parity_v0360.py` 从「把十个色值抄在测试里」改成**三方动态对照**：从官网读出期望值，再核网页版与安卓的 16 组映射（含派生色）。以后改官网配色却漏改任一端，测试当场红。

## 边界与残余

- **安卓源码改了，但这一版不出安装包**。`Theme.kt` 的色板、圆角与字重，`colors.xml` 的窗口底色，以及外观三态偏好都已随源码收进仓库；`versionName` 不动，手机上仍是 0.36.4 的旧配色，要等下一次安卓发版才带上。图标那三色（深底 / 白描边 / mint）不跟页面令牌走，没动。
- 官网页面本身没改，它是这轮对齐的基准。
- 不改模型配置、用户数据、API 行为、自助注册口径与更新通道；`site/version.json` 保持原样。
- 页面仍不请求外部字体、脚本或图片；能力边界照旧如实标注：代码执行需要宿主机 Docker（当前未开）、扫描版 PDF 需先 OCR、离线不可用。
