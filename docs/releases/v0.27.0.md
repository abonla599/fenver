# v0.27.0 更新说明

## 新增了什么

- 意见反馈从「跳出去开 GitHub Issues」改成应用内的一页：正文最多 300 字、最多 4 张截图、可选填邮箱；提交成功后每条带回一个独立编号（形如 FB-000012）
- 管理员界面新增「反馈」收集页：逐条列出每个人发来的反馈（编号、谁、时间、正文、邮箱、截图、已读/未读），顶部报未读条数；截图可直接点开看
- 反馈的删除有门槛：一条反馈要先被标记已读，才能删除；删除时把这条反馈名下的截图一起清掉，编号不回收

## 优化了什么

- 设置页「意见反馈」入口不再离开本应用，点进去就是新的一页（与「检查更新」同一口径：全程留在本机）
