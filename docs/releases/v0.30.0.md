# v0.30.0 更新说明

## 修复了什么

- 修掉「气泡里只剩一个方块」：流式光标此前打的是一个特殊字符，部分手机的字库里没有它，于是渲染成一块实心方块，回答还没开始时整条消息就只剩那个方块。现在光标、步骤的完成/失败/进行中标记、面板的展开箭头全部是画出来的，换任何设备都长同一个样
- 工具步骤的耗时不再有的报毫秒有的不报：面板里所有时长统一成一位小数的秒

## 优化了什么

- 发送问题后键盘自动收起，直接看到输出结果，少一次手动收键盘的动作
- 思考面板改版：标题一行写「查看 N 个步骤 · M 个网页」，点开是每一步做了什么；正在跑的那一步单独一条状态条，右边实时报已经跑了多少秒（像 `18.7s`），面板收起着也看得见它现在在干什么
- 模型还在想、一个字都还没发出来的那几秒，气泡里先给一行「正在思考 •••」，不再只有一条光标干等着
- 思考那一段的排版换成左侧一条竖线 + 矮一档墨色：中文斜体本来就没有真斜体，读着更累
- 网页版（PWA）与原生对齐到同一套：同样的标题文案与步数/网页数、同样画出来的状态标记、同样的实时秒数状态条与「正在思考」占位行，用浏览器打开也是 App 里那个样子。发送后同样收键盘，但只在触屏设备上收——桌面浏览器继续把光标留在输入框里

## 新增了什么

- 应用图标重做：桌面图标、App 内品牌位、网页版 PWA 图标换成同一套「对话气泡 + 思考轨迹 + 火花」，正是这款软件的招牌能力。五种分辨率与自适应图标由 `tools/render-app-icon.ps1` 一次生成，以后换配色重跑一条命令就行
